This file is a template. Set `draft: false` (or delete the line) to publish it.

## How it works

1. Create `src/posts/my-post-slug.md` with the frontmatter above.
2. Write **Markdown** — headings, lists, `code`, images from `/public`, links.
3. Commit and push. The post appears in the blog feed next to Medium,
   Substack and LessWrong, and is readable at `/#blog/my-post-slug`.

> Tip: run `npm run dev` to preview locally.
